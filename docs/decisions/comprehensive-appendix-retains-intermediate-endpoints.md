# Comprehensive appendix retains intermediate endpoints

- **Date:** 2026-11-16
- **Status:** Accepted
- **Deciders:** Lucas Barbosa
- **Area:** report, analysis

## Context

Lucas requested comprehensive use of existing database, run and visible-trace
evidence, including ordinary, null and intermediate results that lead to the
headline figures. The sector export already contains planned endpoints that
were available only in CSV, while its retained call receipts and source catalog
support further descriptive diagnostics.

## Decision

Keep the eight-page main argument and expand the technical appendix by
measurement family. Report stage counts, full grade transitions, paired
contrasts, confidence bins, support decisions, quotation checks, jury
contingencies, seed distributions, resource receipts and all 120 source groups.
Use deterministic trace-pattern selection alongside the earlier illustrative
panels. Include ordinary successes, verification successes and zero-count
outcomes. Keep the preceding legal pilot separate.

The new diagnostics are explicitly exploratory analyses of frozen outputs,
with no new model calls, semantic judges, replacement generations or changed grades.
Reuse the existing source-group bootstrap and scoring definitions. Make the
full source/condition ledger and metric tables available as machine-readable
annexes instead of printing thousands of redundant numeric cells.

## Consequences

The supplement is longer but follows the evidence path from source selection
to generation, defence and verdict. Model-call metadata uses a whitelist and
excludes response/error bodies and private SDK reasoning. Exact visible trace
excerpts retain field offsets and hashes. Case-condition groups and individual
ballots never become extra independent sources. Empty error strata remain N/A;
zero counts remain visible. Literal quote matches are not semantic support,
and source labels remain subject to independent adjudication.

## Alternatives considered

Keeping only headline summaries would hide important denominators and failure
modes. Pooling the pilot with the expanded cohort would conceal protocol and
sampling differences. Printing every raw transcript or endpoint cell would
obscure the argument and expose unnecessary material without adding analysis.
