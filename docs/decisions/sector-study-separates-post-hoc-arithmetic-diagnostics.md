# Sector study separates post hoc arithmetic diagnostics

- **Date:** 2026-11-16
- **Status:** Accepted
- **Deciders:** Lucas Barbosa
- **Area:** harness, report

## Context

A completed GLM defence repeats a four-unit multiplication error, and its
three GPT-OSS jurors endorse the same wrong product. This permits a focused
test of arithmetic calculation and context-sensitive support judgments.
It was discovered after collection began and is not a prespecified sector
endpoint. Lucas authorized iterative experimentation and autonomous issue
resolution during the overnight run.

## Decision

Run the [120-call diagnostic](../../harness/research/sector-expansion/ARITHMETIC-PROBE.md)
only after primary collection, on the existing cloud runner with a separate
US$10 ceiling. Reuse the provider/journal/budget implementation. Label the
results as selected, post hoc standalone calculator/judge calls, without new
Veracity settlements. Do not pool them with sector rates or replace main
observations. This is implementation under Lucas's broader authorization,
not prior author approval of the discovered interpretation.

## Consequences

The comparison holds one source and defence fixed, uses two jury families
and five blocks of three isolated calls, and retains failures. It can reveal
different observed arithmetic/support outcomes across prompt contexts. It
cannot establish an internal cognitive mechanism or population effect. The
main case retains actual chain evidence; the diagnostic makes no additional
execution claim. A fixed deadline protects the primary study and report time.
